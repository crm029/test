# Security notes

This repository currently contains a public portfolio website only.

- No login, admin panel, database, payment flow, or visitor-submitted form is implemented.
- Do not commit passwords, API keys, private contact details, or hosting credentials.
- Keep PHP and the hosting environment updated.
- Serve the site over HTTPS in production.
- Keep directory listing disabled.
- Review hosting-level permissions and backup configuration before launch.
- Report a suspected vulnerability through a private GitHub security advisory for this repository where available; do not publish exploit details in a public issue.

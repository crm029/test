# وب‌سایت شخصی مهدی

وب‌سایت شخصی فارسی، راست‌چین و واکنش‌گرا با PHP، HTML، CSS و JavaScript؛ با هویت بصری سرمه‌ای و طلایی.

## اجرای محلی
1. پوشه پروژه را در `C:\\xampp\\htdocs\\test` قرار بده.
2. Apache را از XAMPP اجرا کن.
3. آدرس `http://localhost/test/` را باز کن.

## ساختار پروژه
- `index.php`: صفحه اصلی، داده‌های پروژه‌ها و سربرگ‌های امنیتی
- `assets/css/style.css`: طراحی واکنش‌گرا و دسترس‌پذیری
- `assets/js/main.js`: منوی موبایل و انیمیشن‌ها
- `assets/img/brand-mark.svg`: لوگوی اصلی
- `assets/img/favicon.svg`: آیکون مرورگر
- `robots.txt`: راهنمای خزنده‌های موتور جست‌وجو

## نکات انتشار
- پروژه برای هاست دارای PHP 8.0 یا بالاتر آماده شده است.
- دامنه، ایمیل رسمی و اطلاعات تماس عمومی باید پیش از انتشار نهایی در صورت نیاز اضافه شوند.
- روی هاست HTTPS را فعال کن؛ پس از آن HSTS را در سطح هاست/CDN تنظیم کن.
- مطمئن شو فهرست‌نمایی پوشه‌ها (Directory Listing) در هاست غیرفعال است.
- این سایت در حال حاضر فرم دریافت اطلاعات، ورود کاربران، پایگاه داده یا پنل مدیریت ندارد؛ بنابراین اطلاعات حساسی از بازدیدکنندگان دریافت نمی‌کند.
- سربرگ‌های امنیتی در PHP تنظیم شده‌اند. تنظیمات نهایی باید پس از استقرار روی هاست واقعی با ابزارهای بررسی امنیتی آزمایش شوند.

## ویرایش محتوا
اطلاعات پروژه‌ها در آرایه `$projects` ابتدای فایل `index.php` قرار دارد. برای افزودن پروژه، یک عضو جدید با عنوان، توضیح، دسته‌بندی و در صورت وجود نشانی معتبر اضافه کن.

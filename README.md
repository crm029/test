# وب‌سایت شخصی مهدی

وب‌سایت تک‌صفحه‌ای فارسی با طراحی واکنش‌گرا، راست‌چین و پالت سرمه‌ای و طلایی.

## اجرا با XAMPP
1. پوشه پروژه را داخل `C:\\xampp\\htdocs\\` قرار بده.
2. Apache را از کنترل پنل XAMPP اجرا کن.
3. در مرورگر آدرس `http://localhost/test/` را باز کن.

## ساختار
- `index.php` صفحه اصلی و محتوای سایت
- `assets/css/style.css` استایل‌ها و طراحی واکنش‌گرا
- `assets/js/main.js` منوی موبایل و انیمیشن ورود بخش‌ها

## شخصی‌سازی
اطلاعات تماس و لینک شبکه‌های اجتماعی هنوز وارد نشده‌اند؛ پس از مشخص شدن آدرس ایمیل و لینک‌ها می‌توان بخش ارتباط را کامل کرد.
